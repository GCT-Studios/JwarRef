Make an Opposed Melee Pool Test against a Target Enemy Immobilised or Held model.  
If successful, the Target gains a Control Marker.  
The Melee Exchange ends as soon as the Enemy model is Controlled. This ends the Activation, if any, remove used Activation Counters along with one Control Marker.
