Use this Ki Feat in the Starting Phase or when this model is Targeted by an Enemy effect or an Enemy model declares an action or resolves an effect that will bring it into BtB with this model while this model is undamaged.  
  
Replace this model by Deploying a Loyal Samurai you own that is currently Elsewhere, and place this model Elsewhere. This model gains the Flank trait and returns to play using those rules. Any action or effect continues against that model.  
  
The Enemy model is now Surprised. Transfer State Markers, Activation Counters and any Tokens to the Samurai’s profile card.
