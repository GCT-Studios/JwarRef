Transfer one [[Bleeding]], [[Blind]], [[Diseased]], [[Death Sentence]], [[Immobilised]], [[Impetuous-state|Impetuous]], [[On Fire]], [[Poisoned]], [[Spirit Block]], or [[Stunned]] State Marker from one non-Soulless model to another non-Soulless model, both models must be within the Pulse.

If this affects an Enemy model, first make one Opp.Ki test against the Enemy model transferring the State Marker, or if transferring from a Friendly model to an Enemy model, test against the Enemy model receiving the State Marker.
