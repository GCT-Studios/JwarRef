When Target Enemy model declares an Opposed Ki Test, this model performs an Opposed Ki Test with that Enemy model.  
If this model wins the Opposed Ki Test, the Enemy model's Ki Feat is not resolved and that model's Activation ends, it removes an Activation Counter.  
This is a Trap effect.
