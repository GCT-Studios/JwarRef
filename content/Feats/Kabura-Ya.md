Target a model at the start of any model's activation, before that model's Action is declared, this model performs a Ranged Challenge (7) test.  
If successful, the Target Enemy model gains [[Slow]] until the end of the current activation and a [[Stunned]] Marker.  
This is a [[Trap]] effect.
